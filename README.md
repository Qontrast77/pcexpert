# Экспертная система подбора конфигурации ПК

Курсовая работа по дисциплине «Интеллектуальные системы и технологии».
Прототип продукционной экспертной системы: по задачам, бюджету и предпочтениям
пользователя подбирает совместимую конфигурацию ПК и объясняет каждое решение
цепочкой сработавших правил.

## Запуск

```bash
pip install -r requirements.txt   # единственная зависимость — Flask
python app.py                     # открыть http://localhost:5000
```

Консольный пример: `python expert.py`

## Проверка

```bash
python -m unittest -v             # 9 тестов по сценариям
python kb_check.py                # проверка полноты и непротиворечивости (≈1 мин)
```

## Структура

| Файл | Назначение |
|---|---|
| `engine.py` | механизм вывода: рабочая память, сопоставление, повестка, разрешение конфликтов (salience + новизна), рефракция, поддержка истинности (TMS), трассировка, деревья вывода |
| `knowledge_base.py` | база знаний — 84 правила в 9 группах |
| `catalog.py`, `data/catalog.json` | справочник комплектующих (80 позиций, ориентировочные цены на ноябрь 2026 г.) |
| `expert.py` | фасад: ввод → факты → вывод → результат с объяснениями |
| `app.py`, `templates/`, `static/` | веб-интерфейс (Flask), REST API `POST /api/recommend`, страница базы знаний `/rules` |
| `tests/test_scenarios.py` | тестовые сценарии |
| `kb_check.py` | массовая проверка базы знаний |

Требуется Python 3.10+.
